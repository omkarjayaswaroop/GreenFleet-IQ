# GreenFleet IQ

A polished front-end decision-support platform for the problem statement:
Quantum-Inspired Fuel Consumption Prediction and Green Fleet Optimization.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Executive dashboard
- Fuel consumption prediction
- Quantum-inspired optimization simulation
- Alternative-fuel scenario comparison
- Benchmark/convergence view
- Interactive controls
- Exportable text report
- Responsive design

## Important
The current coefficients/results are explicitly simulation assumptions for a hackathon decision-support interface. A production system should train/calibrate the prediction model on verified voyage data and connect the optimizer to real operational datasets.
